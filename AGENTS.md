# Leslie Development Instructions

- Build the production Electron application at the repository root.
- Use Nub for Node, dependency management, and package scripts.
- Use React, TypeScript, Tailwind CSS, and Vite+ through `vp`.
- Keep the earlier web prototype isolated in `prototype/`.
- Preserve unrelated changes.
- After each completed task, run relevant checks, commit task-scoped changes, and push directly to `main`.
- Run `gh signoff` for each tested commit after pushing, then verify its signoff status.
