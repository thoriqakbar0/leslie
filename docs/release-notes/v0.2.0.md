# Leslie v0.2.0

Leslie's first public macOS beta keeps planned work and factual work logs side by side.

## What is included

- Capture planned tasks or work that already happened from one composer.
- See planned work and factual timeline entries together.
- Organize work with folders, notes, estimates, labels, and activity history.
- Move through Leslie quickly with keyboard controls.
- Keep app data local in Leslie's SQLite database.

## Install

1. Download and unzip `Leslie-v0.2.0-macOS.zip`.
2. Move `Leslie.app` into the Applications folder.
3. Right-click Leslie and choose Open on the first launch if macOS asks.

This beta is ad-hoc signed and not notarized. It has no cloud sync or automatic updates.
