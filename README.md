# Leslie

Local-first Electron app for planned work and factual work logs. Leslie uses React,
TypeScript, Tailwind CSS, Vite+, and IndexedDB.

The previous product prototype is preserved in `prototype/`.

## Commands

- `vp install` installs the pinned toolchain and dependencies.
- `vp run dev` starts Vite and the Electron window.
- `vp check` formats, lints, and type-checks the root application.
- `vp build` builds the React renderer.
- `vp run start` opens the built Electron application.
